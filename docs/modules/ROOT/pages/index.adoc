= Thumbdrive Multiboot
:description: Multiboot USB sticks with live ISOs, thin Btrfs installs, or both.
:page-audience: end-user
:page-usage-context: product-docs

Thumbdrive Multiboot formats and manages USB sticks for three jobs: **live ISO toolkits**, **thin installed Linux systems**, or **both** on one drive when capacity allows.

Unlike Ventoy-style ISO-only tools, installed mode places full distros in **Btrfs subvolumes** (shared free space, optional zstd compression, snapshots). Every mode still presents a **branded exFAT volume** in Windows File Explorer so the stick is identifiable and, in live/both modes, accepts drag-and-drop ISOs.
